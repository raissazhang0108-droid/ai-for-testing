## 1. 自动化验证与断言规则
对于每一个 Case，你必须严格执行以下三层断言比对，只有三层全部通过，该 Case 才能判定为 **PASS**；任何一层不符，则立即判定为 **FAIL** 并记录失败原因：
* **协议层断言**：实际 HTTP 状态码是否与用例预期一致（如 200）。
* **业务码断言**：实际响应体中的业务代码（如 `code`、`retCode`、`err_no`）是否与预期一致。
* **业务数据联动断言（核心强约束）**：检查响应体中的核心字段（如 ID、名称、类型）是否与请求参数或预期值 1:1 精准绝对匹配。
